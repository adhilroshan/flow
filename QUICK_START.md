## 🆘 Troubleshooting

### "Part of file doesn't exist"

**Problem**: `ai_preferences.g.dart` not found

**Solution**:
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### "No such file or directory: flutter"

**Problem**: Flutter not in PATH

**Solution**:
```bash
export PATH="$PATH:/path/to/flutter/bin"
# OR install Flutter: https://flutter.dev/docs/get-started/install
```

### Build Runner Conflicts

**Problem**: Conflicting outputs

**Solution**:
```bash
flutter pub run build_runner clean
flutter pub run build_runner build --delete-conflicting-outputs
```

### Analysis Errors After Build

**Problem**: Code analysis shows errors

**Solution**: Check AUDIT_REPORT.md and ensure all commits are pulled:
```bash
git pull origin claude/integrate-gemma-local-inference-012YkQVGqT2DW6aWbtnrwn9i
```
